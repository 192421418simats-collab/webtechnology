🌐 Internet Protocol Observation

This experiment demonstrates how to observe website requests using the browser's Developer Tools.

Steps to Perform

  1. Open Google Chrome or Microsoft Edge.
  2. Visit any website (example: https://www.google.com).
  3. Press F12 to open Developer Tools.
  4. Select the Network tab.
  5. Refresh the webpage.
  6. Observe the request details shown below.
