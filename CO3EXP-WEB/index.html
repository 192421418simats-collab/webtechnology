Exp # Experiment Title Core Concept & Requirements Action
1 DOM-Based Student Profile Manipulation Display and modify student profile details using getElementById(), querySelector(), textContent, style, classList, and setAttribute(). Options to change heading, text color, background color, and show/hide profile. Open →
2 Dynamic Student Registration List Using DOM Create a student registration interface to add, display, and remove student records dynamically. Use createElement(), appendChild(), remove(), parentElement, and children. Includes Student Name, Register Number, Department, Remove, and Clear All. Open →
3 Interactive Event Registration Using JavaScript Events Demonstrate onclick, onchange, input, focus, blur, mouseover, mouseout, and addEventListener(). Comparative table comparing intrinsic handling vs addEventListener(). Open →
4 Browser Information Dashboard Using Window Object Displays current URL, browser language, online status, screen width/height, viewport width/height, and scroll position. Use window.location, innerWidth, innerHeight, scrollX, scrollY, navigator, screen. Open →
5 Cross-Browser Compatible Interactive Webpage Feature detection and fallback techniques for unsupported features. Check support for localStorage, querySelector(), and CSS @supports layout fallbacks for noncompliant engines. Open →
6 Basic Java Servlet for Dynamic Content Generation Create a Java Servlet displaying welcome message, student name, course name, and current date/time timestamp. Use HttpServlet, doGet(), HttpServletRequest, HttpServletResponse, PrintWriter. Open →
7 Student Registration Form Processing Using Servlet Design HTML student registration form and process using Servlet. Include Student Name, Register Number, Email, Department, and Semester. Use doPost() and request.getParameter() with validation. Open →
8 Online Student Result Processing Using Servlet Servlet-based result-processing system for 5 subjects. Calculate Total, Average, Highest/Lowest Mark, Grade, and Pass/Fail status. Validate missing, non-numeric, or out-of-range marks. Open →
9 Servlet Lifecycle Demonstration Create a servlet to demonstrate the constructor, init(), service()/doGet(), and destroy() methods. Track and record how many times each lifecycle method executes. Open →
10 Thread-Safe Concurrent Visitor Counter Using Servlet Develop an unsafe visitor counter using a servlet instance variable and analyze the race-condition problem. Implement a thread-safe version using AtomicInteger or synchronized blocks. Open →
