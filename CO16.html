About XHTML

XHTML stands for Extensible HyperText Markup Language.
It is a stricter version of HTML and follows XML rules.
Every tag must be properly closed.
Attributes must always be enclosed in quotes.

Features of XHTML

  • All tags are written in lowercase.
  • Every opening tag has a closing tag.
  • Attributes are always inside quotation marks.
  • Elements are properly nested.
  • Empty tags use self-closing syntax like <br /> and <hr />.
