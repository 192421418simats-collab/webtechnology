The table below is generated dynamically by applying transform.xslt against courses.xml in your browser. It filters courses with students > 60 and sorts them in descending order of enrollment.

Explanation of XSLT Components Code Guide
1. <xsl:stylesheet>

Declares the root XSLT element and defines the W3C transformation namespace xmlns:xsl="http://www.w3.org/1999/XSL/Transform".

2. <xsl:output method="html" .../>

Instructs the engine to format the result tree as valid HTML4/5 markup with proper indenting.

3. <xsl:template match="/">

Matches the XML document root node, serving as the entry point to construct the HTML page shell.

4. <xsl:for-each select="...[students > 60]">

Iterates through <course> elements and applies predicate filtering for enrollment greater than 60.

5. <xsl:sort select="students" .../>

Sorts matched courses numerically (data-type="number") in descending sequence (order="descending").

6. <xsl:value-of select="..."/>

Extracts values from tags (e.g., code, name) and attribute @id into HTML table cells.
