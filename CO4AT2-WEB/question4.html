Visual MVC Flow Diagram

Step 1
View ➔ Controller: User inputs employee information on the form. The View captures the submit event and passes payload to Controller.
Step 2
Controller ➔ Model: Controller invokes Service validation & updates Model. Unique ID check and field requirements are validated.
Step 3
Model ➔ Result View: On validation pass, Model updates state and Controller formats data to display on the Result View card.
📚

MVC Architecture Component Breakdown

📦 The Model (Data & Integrity)

Represents the application's data structure and business rules. In Employee IQ, the Model manages attributes like employeeID, employeeName, department, and enforces uniqueness validation.

🖥️ The View (User Interface)

Responsible for presenting data to the user. Includes form controls (radio buttons, text areas) and the Result View that dynamically displays success output or validation error banners.

🎮 The Controller / Service (Logic Bridge)

Acts as an intermediary. It receives raw form input from the View, triggers validation logic in the Service layer, updates the Model, and determines which Result View response to display.
